# Navigation shortcuts for nano editor
- ^O : Save file
- ^X : Exit editor
- ^V : Next page
- ^Y : Prev page
- ^K : Delete curr line
- crtl + shift + 6 : Selection cursor
- ^U : Undo deleted text
- ^A : Skip to front of line
- ^E : Skip to end of line
- ![name_to_give_the_image](path) : embedding an image
