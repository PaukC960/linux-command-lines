# Linux Commands
## Basic Navigation
- whoami : username
- man <command> : manual for the command ('q'+enter to 'quit')
- pwd : current/ working directory
- ls : list all the files in the folder
- cd : change directory
- clear : clear the terminal 
- open : open a file/ directory
- open . : open a new terminal window of the current directory

## Editing Directories
- mkdir mydir : make a new directory called "mydir"
- rm mydir : delete/ remove mydir
- touch myfile : creat a new file in the currnet directory
	(use .md for files to use Markdown editing format)
- nano myfile : edit the file
- rm : remove file
- rmdir : remove directory
